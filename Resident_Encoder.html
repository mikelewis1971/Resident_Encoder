About the Secure Identity Vault

🎯 Purpose

This tool acts as a secure bridge between our highly restricted offline files and our AppSheet cloud database. It converts sensitive Personally Identifiable Information (SSN, DOB) into an anonymous, 32-byte identifier that can be used safely in the cloud without exposing the resident's true identity.

⚙️ How to Use It

  • Master Mode (In Office): Click "Load Master CSV" and select the Master Database from our secure Network/USB Drive. Generate new keys for intakes. When prompted, save the downloaded CSV to overwrite the old Master file on the Network Drive.
  • Field Mode (Out of Office): If you do not load a CSV, the tool operates in Field Mode. New records are temporarily and securely cached in your laptop's local memory.
  • Syncing: Upon returning to the office, load the Master CSV. The tool will prompt you to merge your pending offline records into the master file automatically.

🛡️ Why This Protects Client Anonymity

  • 100% Offline Processing: This tool runs entirely in your computer's local memory (RAM). It makes zero network requests to Google or the internet.
  • One-Way Cryptography: We use the SHA-256 algorithm. It is mathematically impossible to reverse-engineer the generated Primary Key back into a Social Security Number or Date of Birth.
  • Zero Cloud Exposure: Because we only paste the anonymous Primary Key into AppSheet, a cloud data breach would yield nothing but useless strings of letters and numbers, keeping our clients totally shielded.
